# Avaloka Assignment: Data Structures & Systems Design

Solutions for the take-home assignment from Avaloka (Guruvai Sciences).

## Files

- `lru_cache.py` - Problem 1: LRU Cache using a dictionary and a doubly linked list. `get` and `put` run in O(1) average time.
- `event_scheduler.py` - Problem 2: `can_attend_all` and `min_rooms_required` using sorting and a min-heap. Both run in O(n log n).

## How to run

Python 3, no extra libraries needed.

```
python lru_cache.py
python event_scheduler.py
```

Each file runs its own test cases and prints the output. The expected results are written as comments next to each test.
